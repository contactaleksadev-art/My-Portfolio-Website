# 🚀 My First Portfolio Website

Welcome to the repository for my very first portfolio website! I am an aspiring **Software Developer** who is passionate about building clean, functional, and user-friendly web applications. This project serves as a showcase of my journey, current skill set, and the growth I am achieving every day as a new developer.

## 🌟 About the Project

This portfolio was built to introduce myself to the tech world, share my background, and display the projects I have been working on. Building this site allowed me to practice core development principles and experiment with design, layout, and responsive web design.

## 🛠️ Tech Stack & Skills

Here are the primary technologies and tools I used to build this website:

* **HTML5** – Structuring the web content and ensuring semantic layout.
* **CSS3** – Styling, custom layouts, and responsive design for mobile and desktop viewports.
* **JavaScript** – Adding interactivity and dynamic elements to the user interface.
* **Git & GitHub** – Version control and hosting the source code.

## 📈 Learning Objectives

As a new developer, every project is a chance to learn. While building this portfolio, I focused on:

* Writing clean, readable, and maintainable code.
* Understanding responsive design patterns so the site looks great on all device sizes.
* Deploying a live website to the web for the first time.
